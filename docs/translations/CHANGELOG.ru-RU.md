## [0.2.2] — 2026-05-05

### Добавлено
- Хронология активности в реальном времени — в панель управления добавлен раздел «Текущая сессия», показывающий индексированные (staged) изменения в реальном времени.
- Детекция индексированных изменений — `graphx status` и панель управления теперь корректно идентифицируют и отображают файлы в индексе git.
- Команда `/graphx-status` — новый явный триггер CLI для отображения панели состояния проекта.
- Автоматическая настройка панели управления — `activity.json` и `index.html` теперь автоматически генерируются при первом запуске `/graphx`.

### Исправлено
- Улучшена согласованность модели данных между `activity.py`, `status.py` и панелью управления.
- Исправлена логика diff в GitPython для точного отчета об индексированных изменениях с использованием `repo.index.diff("HEAD")`.
- Добавлено отсутствующее поле `size` для индексированных изменений в `activity.json` для совместимости с панелью управления.

## [0.2.1] — 2026-05-05

### Добавлено
- Глобальная команда `/graphx` для OpenCode — `graphx install --platform opencode` теперь регистрирует глобальную команду `/graphx` в `~/.config/opencode/commands/graphx.md`
- Шаблон команды `/graphx` выполняет `graphx $ARGUMENTS` — без аргументов запускает `graphx watch .`, с аргументами передаёт их дальше (например, `/graphx status`, `/graphx query "..."`)

### Исправлено
- `graphx opencode uninstall` теперь удаляет файл команды `/graphx` вместе с плагином
- `skill-opencode.md` обновлён: документированы `/graphx` и `/graphx status`

## [0.2.0] — 2026-05-05

### Добавлено
- Интерактивная панель отслеживания активности — `graphx-out/activity.json` генерируется из истории git с детекцией AI- и человеческих коммитов
- Динамичное SPA-приложение `index.html`, которое опрашивает `activity.json` каждые 30 секунд для обновления в реальном времени
- Хронология активности показывает хеш коммита, автора, временную метку, сообщение и изменения файлов с метками A/M/D
- Раздел статуса git с текущей веткой, индексированными изменениями, неотслеживаемыми ветками
- Рейтинг «горячих» файлов, диаграмма скорости изменений, коммиты слияния, внешние файлы, большие файлы
- Новый модуль `activity.py` с эвристикой `_is_ai_commit()` для детекции коммитов, созданных AI
- `index.html` рендерится полностью из `window.INITIAL_DATA` без зависимостей сборки при загрузке страницы

### Исправлено
- `skill.md` обновлён: документирована возможность отслеживания активности в реальном времени

## [0.1.0] — 2026-04-03

### Добавлено
- Первый релиз
- Извлечение AST для 13 языков через tree-sitter (Python, JS, TS, Go, Rust, Java, C, C++, Ruby, C#, Kotlin, Scala, PHP)
- Детекция сообществ Leiden через graspologic с разделением перегруженных сообществ
- Семантический кэш SHA256 — повторные запуски пропускают неизменённые файлы
- MCP stdio сервер — `query_graph`, `get_node`, `get_neighbors`, `shortest_path`, `god_nodes`
- Петля обратной связи с памятью — результаты Q&A сохраняются в `graphx-out/memory/`, извлекаются при `--update`
- Экспорт хранилища Obsidian с вики-ссылками, тегами сообществ, раскладкой Canvas
- Модуль безопасности — валидация URL, безопасное скачивание с ограничением размера, защита путей, очистка меток
- CLI `graphx install` — копирует навык в `~/.claude/skills/` и регистрирует в `CLAUDE.md`
- Параллельное извлечение субагентами для документов, статей и изображений
